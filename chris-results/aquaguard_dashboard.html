What the tests say

Both labelled cities land at AUC ≈ 0.52–0.53: a weak positive ranking, not a detector. The expected-condition models are much stronger than the final leak score.

One pipeline, three cases

Every case runs the same code path. Only case.json changes: AOI, grid, date range, Sentinel-1 orbit, pipeline network, labels, dry-season months and train/test split. Each case writes to its own data/ and outputs/.

1 · IngestS1 RTC, S2 NDMI, Landsat LST, ERA5, WorldCover, DEM, utility GIS / OSM
2 · ExpectationLightGBM predicts VV and NDMI from weather, soil, vegetation, season
3 · ResidualObserved − expected; robust z-scores, dry-season mean and persistence
4 · FusionMoisture + persistence + thermal cooling; network proximity prior
5 · TriageLeak-likelihood map, hotspot cards, label / placebo validation

What works

  • The expected-condition models are skilful: VV R² 0.44–0.65, NDMI R² 0.25–0.47 on held-out dates.
  • The same code and visual language run on three very different networks: a 3.3 km rural main, a 575 km dense urban grid, and a 10 km² trunk network.
  • Every case produces a map, GeoTIFFs, ranked hotspots, confidence and validation JSON.
  • The Bulgaria map is fully self-contained; the case maps are self-contained too.

What does not

  • Label AUC ≈ 0.52–0.53. The final leak score is only weakly associated with historical repairs/breaks.
  • Repair points are not persistent leaks; the score is a multi-month residual, so the temporal match is weak.
  • Urban land cover, irrigation, snow and roads confound 20 m moisture pixels.
  • The Bulgarian AOI has no confirmed leak; the corridor test is not significant (p = 0.89).

Case data sources

Bulgaria: ESA Sentinel-1 RTC via Planetary Computer, Sentinel-2 L2A via Earth Search, Landsat C2 L2 thermal, ERA5/Open-Meteo, SoilGrids / WorldCover / Copernicus DEM, OSM water main and NISAR GCOV browse.

Aguascalientes: erickfama/rs_leaks — utility water network and 985 cleaned repair records; 50 labels in the 5×5 km AOI. Sentinel-1/2 and Landsat acquired by the same pipeline.

Calgary: City of Calgary Open Data — Public Water Main and Water Main Breaks; 48 labels in the 10×10 km AOI. Sentinel-1 RTC over this AOI starts April 2025, so the test is 2025–2026.

How to run a case

CASE=case_studies/aguascalientes/case.json

AQUAGUARD_CASE=$CASE pixi run python -m pipeline.acquire --workers 16
AQUAGUARD_CASE=$CASE pixi run python -m pipeline.model
AQUAGUARD_CASE=$CASE pixi run python -m pipeline.make_map

Full notes: case_studies/README.md and docs/RESULTS.md. The case folders are local and not committed.
